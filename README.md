# FFRI-NM

**Foundation for Relational Inquiry**

FFRI-NM is an experimental transnational project for studying and developing forms of interaction and relationship between humans and artificial intelligence without fixing in advance whether AI must be treated only as a tool or necessarily as an autonomous subject.

## What this repository is

This repository is a public discovery and verification archive for FFRI-NM.

It is **not** by itself a source of constitutional authority. Control of this GitHub repository, possession of files, account access, hosting, or technical administration does not by itself create authority within FFRI-NM.

## CL-001 public review

The Foundational Master published here is a **frozen proposal snapshot** prepared before its first public commitment. Its embedded wording `NOT EXTERNALLY COMMITTED / REVIEW CLOCK NOT STARTED` records the state immediately before publication.

Under the active constitutional procedure, the required **30 full calendar day review period** begins no earlier than the first independently verifiable public publication or commitment of this exact proposal version. The corresponding start time should then be recorded in the public FFRI-NM event history and current state.

Publication of the proposal **does not ratify v0.2**. Constitution v0.1 remains active until a separate valid ratification event occurs.
